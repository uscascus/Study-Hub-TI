# Study Hub TI

Este repositório é o meu espaço de organização acadêmica durante o curso de Ciência da Computação no CEUB.

A ideia é reunir anotações, atividades, projetos e certificados sem deixar os arquivos espalhados. A estrutura vai crescer junto com as disciplinas, mantendo o mesmo padrão para facilitar revisões e acompanhar minha evolução.

## Organização

- `01_Apresentacao_e_Perfil`: apresentação, contatos e materiais de perfil.
- `02_Disciplinas_Atuais`: atividades, anotações e projetos separados por disciplina.
- `03_Projetos_e_Certificados`: projetos autorais e certificados concluídos.
- `04_Recursos_e_Referencias`: guias, links e referências que realmente usei.
- `entrega`: versão em PDF da etapa inicial do projeto.

## Como pretendo manter o repositório

- Atualizar as pastas durante o semestre, sem esperar o fim da disciplina.
- Usar nomes claros e evitar arquivos como `final_agora_vai_2`.
- Criar um README próprio para projetos maiores.
- Registrar também correções e aprendizados, não apenas resultados prontos.
- Não publicar senhas, chaves, dados pessoais de terceiros ou materiais sem autorização.
