Olá, meu nome é Lucas Coutinho e curso Ciência da Computação no CEUB. Este é o Study Hub TI, meu espaço para organizar o que produzo durante o curso e transformar esse material em um portfólio. Cada projeto tem um README que explica o objetivo, as tecnologias, como executar e quais são os limites. Essa organização ajuda tanto na revisão das matérias quanto na apresentação do trabalho para outras pessoas.

04

2:20–3:25 · 1 minuto e 5 segundos

Demonstre o planejador

Abrir Planejador de estudos ↗

Fazer e falar, nesta ordem

  1. Adicionar: digite “Revisar os comandos do Git” e clique em Adicionar +. O prazo é opcional.O planejador permite registrar uma tarefa de estudo e definir um prazo, se eu precisar.
  2. Concluir: marque o círculo ao lado da tarefa.Ao terminar a atividade, marco a tarefa como concluída.
  3. Filtrar: escolha Pendentes, depois Concluídas.Os filtros separam o que ainda preciso fazer do que já foi concluído.
  4. Recarregar: atualize a página pelo botão do navegador.A tarefa continua salva depois de recarregar, porque os dados ficam no armazenamento local do navegador.
  5. Encerrar: volte para Todas as tarefas.Não há conta nem sincronização entre dispositivos. Se eu limpar os dados do navegador, perco a lista. Neste projeto, pratiquei JavaScript, eventos, validação de dados e testes das regras das tarefas.

O Git registra as mudanças em commits com objetivos específicos. A primeira versão web fica identificada pela tag 1.0.0, e a evolução dos materiais pela versão 1.1.0. O trabalho acontece em uma branch própria, mantendo a etapa inicial na main.

Depois, comente os testes

Os testes verificam inclusão, conclusão, filtros, exclusão, datas e recuperação de dados. Além deles, é preciso conferir o uso real no navegador. O guia de contribuição explica como abrir uma issue, propor uma alteração e pedir revisão por pull request. O histórico e o changelog permitem acompanhar o que mudou entre as versões.
