# Arquivos do GitHub Pages

Esta pasta é a raiz pública do site. Não coloque aqui credenciais, arquivos privados nem anotações que não devam ser publicadas.

- [Página inicial](index.html): perfil, projetos, percurso, materiais e contatos.
- [Planejador](projetos/planejador/index.html): aplicação pessoal em JavaScript.
- [Apresentação](materiais/apresentacao.html): slides e roteiro de cinco minutos.
- `materiais/*.pdf`: cópias dos PDFs para acesso direto no site.
- `assets`: estilos, foto e favicon; não há serviços de análise ou bibliotecas carregadas de terceiros.

As cópias dos PDFs em `docs/materiais` devem ser idênticas às versões de `entrega`. A publicação usa `/docs` na branch `Pitu/bootcamp-intermediaria`.

Execute `python -m http.server 8000 --directory docs` na raiz do repositório para testar. Consulte [CONTRIBUTING.md](../CONTRIBUTING.md) antes de propor mudanças.
