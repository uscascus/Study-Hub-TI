# Entrega inicial

O PDF desta pasta reúne o perfil, a matriz de disciplinas, a arquitetura planejada do GitHub e o roteiro do vídeo.

Antes da submissão na Sala Online, ainda é necessário:

- informar turma ou período;
- substituir as linhas provisórias da matriz pelas disciplinas reais;
- criar o documento-base no Google Docs e liberar como leitor;
- gravar o vídeo horizontal de até 5 minutos e publicar no YouTube;
- inserir os links públicos do Google Docs e do YouTube no PDF final;
- testar todos os links em uma janela anônima.
